# AGENTS.md

Указатель для любых ИИ-агентов и инструментов (включая OMC), работающих
в этом репозитории. Не дублирует — **ссылается**.

## Что прочитать первым делом

1. `CLAUDE.md` — quick start: стэк, структура, команды, конвенции,
   старт сессии, оркестрация (OMC)
2. `docs/progress.md` — последняя запись + «Следующий шаг» = текущий
   приоритет
3. `docs/roadmap.md` — активный этап
4. `docs/decisions.md` — ADR (не нарушать без нового ADR; большой файл,
   читать grep'ом)
5. `backend/CLAUDE.md` / `frontend/CLAUDE.md` — специфика при работе в
   соответствующей части

## Принципы работы

- Атомарные коммиты, Conventional Commits со scope (см. `CLAUDE.md`).
- Документация обновляется **в том же коммите**, что и код
  (ADR / gotcha / api-contract). Подробнее — `docs/doc-hygiene.md`.
- Изменение схемы БД — только через Liquibase-миграцию.
- Изменение REST-контракта — только с обновлением `docs/api-contract.md`
  + регенерацией `frontend/src/shared/api/types.ts`.
- Билды/тесты — не на каждый чих (см. `CLAUDE.md` «Когда что запускать»).
- Независимый code review после крупных этапов — обязателен.
- Не коммитить секреты; HAR'ы и ключи — вне репо.
