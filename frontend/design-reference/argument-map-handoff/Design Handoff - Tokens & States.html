06

Empty states

Каждый пустой экран должен мотивировать первое действие. Иллюстрация (схематичная, в стиле графа) + название + одно-два предложения + основной CTA.

Empty · нет тем первое создание
.state-block

Начните свой первый аргумент

Темы — это структурированные дискуссии, где аргументы становятся узлами, а связи — отношениями.

Empty · нет результатов поиска filter result
smaller variant

По запросу «...» ничего не найдено

Попробуйте: убрать огласовки · сократить · искать в обоих языках

Empty · коллекция пуста inside content
inline panel

Коллекция «Избранное» пуста

Добавьте книги через ♡ на карточке в библиотеке.

/* React component */
export const EmptyState = ({
  illustration, title, body, primary, secondary
}) => (
  <div className="state-block">
    <div className="state-block__illus">{illustration}</div>
    <h3 className="state-block__title">{title}</h3>
    <p className="state-block__body">{body}</p>
    <div className="state-block__actions">
      {primary && <Button variant="primary">{primary}</Button>}
      {secondary && <Button variant="ghost">{secondary}</Button>}
    </div>
  </div>
);
07

Error states

Тон спокойный, не алармистский. Скажите что произошло одним предложением, дайте кнопку «Повторить» или путь обратно. Цвет — серый (для info-tier) или приглушённый красный (для destructive).

Error · 404 not found page-level
.state-block

Здесь ничего нет

Возможно, тема удалена или вы зашли по старой ссылке.

Error · network auto-retry
.state-block

Нет соединения

Проверьте подключение. Повтор через 5с… (3/5)

Error · permission access
.state-block

Тема приватная

Запросите доступ у автора или вернитесь к публичным.
