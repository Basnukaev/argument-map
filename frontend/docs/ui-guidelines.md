# UI Guidelines (frontend)

Дизайн-система и визуальные правила для фронтенда Argument Map. Опора
для всех компонентов и страниц.

## Общий стиль

- **Минималистичный, чистый, профессиональный** — фокус на содержание,
  не на украшения
- **Светлая тема по умолчанию.** Тёмная — после MVP
- **Шрифт:** системный стек (`-apple-system, BlinkMacSystemFont,
  "Segoe UI", Roboto, ...`). При желании подключить — `Inter` через
  `@fontsource/inter`
- **Скругления:**
  - `rounded-lg` (8px) для карточек узлов, модалок, блоков
  - `rounded-md` (6px) для кнопок, инпутов
  - `rounded-full` для аватарок, бэйджей
- **Тени:** минимально, `shadow-sm` для карточек, `shadow-lg` для
  модалок
- **Отступы:** Tailwind шкала. `gap-4` (16px) — стандарт между
  элементами, `gap-2` (8px) — внутри плотных групп
- **Анимации:** только для важных переходов (открытие модалки, drag),
  длительность `duration-150` или `duration-200`. Никаких "красивых"
  эффектов "потому что можно"

## Цвета статусов узлов (ключевая визуальная фича)

Цвет показывает результат алгоритма пересчёта статуса:

| Статус | Назначение | Tailwind классы |
|---|---|---|
| `STANDING` | поддержан, не опровергнут | `bg-green-100 border-green-500 text-green-900` |
| `DISPUTED` | есть и за, и против | `bg-amber-100 border-amber-500 text-amber-900` |
| `REFUTED` | опровергнут | `bg-red-100 border-red-500 text-red-900` |
| `UNVERIFIED` | не оценён | `bg-gray-100 border-gray-400 text-gray-700` |

Граница (`border-2`) — основной носитель цвета, заливка — лёгкая
подкладка. Текст внутри карточки — тёмный для контраста.

## Цвета и стили типов рёбер

Цвет и стиль линии передают тип связи:

| Тип | Семантика | Стиль |
|---|---|---|
| `SUPPORTS` | поддерживает | `stroke-green-500`, толщина 2 |
| `REFUTES` | опровергает | `stroke-red-500`, толщина 2 |
| `INVALIDATES` | мета-опровержение (kill) | `stroke-red-700`, толщина 3, **пунктир** |
| `QUALIFIES` | уточняет применимость | `stroke-blue-500`, толщина 2 |
| `RESPONDS_TO` | организационная связь | `stroke-gray-400`, толщина 1.5 |

Подпись на ребре — короткая (иконка `→` `⇒` или текст
`SUPPORTS`/`REFUTES` в бэйдже). Подпись опциональна — при перегруженном
графе пользователь может скрыть.

## Кастомный узел React Flow

Базовая структура карточки узла:

```
┌────────────────────────────────┐  ← цветная рамка по статусу
│ [иконка] Тезис                 │  ← заголовок: тип узла
│                                │
│ Краткий контент, обрезается до │  ← основное содержимое
│ ~150 символов с многоточием... │
│                                │
│ ●●●●●●○○○○  abdullah           │  ← вес 6/10 + автор
└────────────────────────────────┘
```

### Заголовок
- Иконка типа: `❓` `QUESTION` / `📜` `CLAIM` / `💬` `ARGUMENT` /
  `📚` `EVIDENCE` (или SVG-иконки lucide-react)
- Подпись типа: `Вопрос` / `Тезис` / `Довод` / `Свидетельство`

### Тело
- `content` обрезается до ~150 символов с `…`
- Полный текст показывается в tooltip при наведении
- Длинный контент целиком — в боковой панели деталей при клике

### Футер
- **Вес:** 1-10 точками (заполненные / пустые) или мини-прогресс-баром
- **Автор:** username (когда появится UserSummary в API)
- **Метки:** иконка скрепки если есть привязанные источники, иконка
  человека если есть привязанные авторитеты — компактно

### Состояния
- **Hover:** лёгкое поднятие (`shadow-md`), tooltip с полным контентом
- **Selected (клик):** более яркая рамка (`border-4`), боковая панель
  открыта
- **Dragging:** полупрозрачность 0.7

## Страницы

### `/topics` — Список тем
Главная страница после входа. Показывает все темы пользователя.

**Состав:**
- Заголовок "Темы"
- Поле поиска (фильтрация по `title` локально, на бэке поиска по
  темам пока нет)
- Кнопка "Создать тему" (top-right)
- Сетка карточек тем (`TopicCard`) — 1-3 колонки в зависимости от
  ширины

**TopicCard:**
- `title`
- `description` (truncated)
- Дата создания
- Бэйдж "X узлов / Y связей" (опционально, если будет дешёвый счётчик
  на бэке)
- При клике — переход на `/topics/{id}`

### `/topics/new` — Создание темы
Форма:
- Название (`title`, max 200)
- Описание (`description`, max 2000, опционально)
- Корневой вопрос (`rootQuestion`, max 10000)
- Кнопки "Отмена" / "Создать"

После создания — редирект на `/topics/{id}` (граф темы).

### `/topics/{id}` — Граф темы
**Главная рабочая поверхность.**

Layout:
```
┌──────────────────────────────────────────┬────────────┐
│ [< К списку]  Название темы    [Тулбар]  │            │
├──────────────────────────────────────────┤  Боковая   │
│                                          │  панель    │
│                                          │  деталей   │
│         React Flow Canvas                │  узла      │
│         (зум, пан, drag)                 │  (open on  │
│                                          │   select)  │
│                                          │            │
│                                          │            │
└──────────────────────────────────────────┴────────────┘
```

**Тулбар (top-right под header):**
- "Добавить узел" → `AddNodeDialog`
- "Добавить связь" → `AddEdgeDialog`
- Зум +/-, "По размеру", "Сбросить вид"
- Toggle "Подписи рёбер" (показать/скрыть)

**Canvas:**
- React Flow с кастомными `nodeTypes` (по `NodeType`) и `edgeTypes`
  (по `EdgeType`)
- Автолейаут через `dagre` при первой загрузке (горизонтально:
  корневой `QUESTION` слева)
- Drag-and-drop узлов — позиции сохраняются в стейте, **не** на бэке
  (бэк не знает о позициях; клиентский стейт)
- Mini-map в правом нижнем углу (после MVP — TODO в roadmap)

**Боковая панель (открывается при клике на узел):**
- Полный `content`
- `nodeType`, `status`, `weight`
- `createdBy`, `createdAt`, `updatedAt`
- Кнопки: "Редактировать", "Удалить"
- Список привязанных источников (`NodeSourceList`)
- Список привязанных авторитетов (`NodeAuthorityList`)
- История ревизий — раскрывающийся блок

## Компоненты

Список переиспользуемых компонентов и их назначения:

### UI базовые (`components/ui/`)
- `Button` — варианты `primary` / `secondary` / `ghost` / `danger`
- `Input` — текстовые поля
- `Textarea` — для длинных текстов (content узлов)
- `Select` — выпадающие списки (тип узла, тип ребра, stance)
- `Card` — обёртка с border + padding
- `Modal` / `Dialog` — модальные окна
- `Tooltip` — для hover-подсказок
- `Badge` — маленькие метки (тип, статус)
- `Spinner` — лоадер

### Графовые (`components/graph/`)
- `GraphCanvas` — обёртка React Flow
- `ArgumentNode` / `ClaimNode` / `QuestionNode` / `EvidenceNode` —
  кастомные узлы по типам
- `SupportsEdge` / `RefutesEdge` / `InvalidatesEdge` /
  `QualifiesEdge` / `RespondsToEdge` — кастомные рёбра

### Доменные (`components/`)
- `TopicCard` — карточка темы в списке
- `NodeDetailPanel` — боковая панель деталей узла
- `AddNodeDialog` — модалка создания узла
- `AddEdgeDialog` — модалка создания связи (выбрать from, to, тип)
- `EditNodeDialog` — модалка редактирования контента
- `SourceList` / `AuthorityList` — списки в панели деталей
- `AttachSourceDialog` / `AttachAuthorityDialog` — модалки привязки
- `RevisionHistory` — раскрывающийся список ревизий узла

## Responsive

- **Desktop-first:** граф плохо работает на мобилках (drag-and-drop,
  чтение мелкого текста)
- **Минимальная ширина страницы графа:** `1024px`. На меньшем —
  показывать сообщение "Откройте на десктопе для лучшего опыта" с
  read-only-режимом графа (просмотр без редактирования)
- **Список тем и форма создания:** адаптивные, работают на любой ширине
- **Брейкпоинты Tailwind:** стандартные (`sm`, `md`, `lg`, `xl`,
  `2xl`)

## Accessibility (a11y)

- Семантический HTML: `<button>`, не `<div onClick>`
- `aria-label` для иконок-кнопок без текста
- Keyboard navigation: `Tab`, `Enter`, `Esc` для модалок
- Focus-visible: явные кольца фокуса (`focus-visible:ring-2`)
- Контрастность текста: минимум `WCAG AA` (4.5:1) — проверять
  цветовую палитру
- React Flow имеет встроенную поддержку клавиатурной навигации —
  не отключать

## Локализация

- MVP — только русский. Тексты UI в коде на русском
- При появлении второй локали — выносить в `i18n` (`react-i18next` —
  отдельный ADR)
- Технические термины (типы узлов, статусы) — русские в UI, английские
  в коде

## Иконки

- **Lucide React** (`lucide-react`) — основной набор. Современные,
  лёгкие, тонкая обводка
- Для эмодзи (типы узлов в карточках) — допустимо использовать
  юникод-символы (быстро, без зависимостей), но убедиться что
  отображаются на всех платформах
