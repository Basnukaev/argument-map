# Argument Map

Монорепозиторий проекта Argument Map — API-first приложение для построения
карт аргументации. Позволяет строить графы дискуссий: вопросы, тезисы,
аргументы, контр-аргументы, источники и мнения учёных.

## Структура репозитория

```
argument-map/
├── README.md                   — этот файл
├── docker-compose.yml          — общая инфраструктура (Postgres)
├── .gitignore
│
├── docs/                       — ОБЩАЯ документация проекта
│   ├── architecture.md         — высокоуровневая архитектура
│   ├── er-diagram.md           — ER-диаграмма БД
│   ├── glossary.md             — термины проекта
│   ├── roadmap.md              — план работ (бэк + фронт)
│   ├── progress.md              — журнал сессий работы
│   ├── decisions.md            — архитектурные решения (ADR)
│   ├── gotchas.md              — известные ловушки
│   └── api-contract.md         — контракт между беком и фронтом
│
├── backend/                    — Java/Spring Boot
│   ├── CLAUDE.md               — конфиг Claude Code для бэка
│   ├── docs/                   — бэкенд-специфичная документация
│   │   ├── coding-standards.md
│   │   ├── antipatterns.md
│   │   └── api-design.md
│   ├── pom.xml

│
└── frontend/                   — появится позже
    ├── CLAUDE.md
    ├── docs/

    └── src/
```

## Принципы монорепы

- **Независимые части:** `backend/` и `frontend/` — полностью самостоятельные
  подпроекты со своей сборкой, зависимостями и тестами. Никаких shared-модулей.
- **Общая документация:** всё, что описывает *продукт* (архитектура, термины,
  решения, roadmap), живёт в корневом `docs/`. Всё, что специфично для
  технологии, — в `backend/docs/` или `frontend/docs/`.
- **Один git:** история общая, PR могут затрагивать и бэк, и фронт одновременно
  (например, при изменении API-контракта).
- **Инфраструктура общая:** `docker-compose.yml` в корне поднимает Postgres,
  который нужен и беку для работы, и фронту для e2e-тестов.

## Работа с Claude Code

Claude Code нужно запускать **внутри соответствующей подпапки**:

```bash
cd backend && claude    # для работы над бэкендом
cd frontend && claude   # для работы над фронтендом (когда появится)
```

Claude Code прочитает `CLAUDE.md` из текущей директории и будет работать
в контексте именно этой части проекта. Общие документы из корневого `docs/`
доступны через относительный путь `../docs/`.

Для задач, которые затрагивают обе части одновременно (например, изменение
API-контракта), работать в корне репы и явно указывать Claude Code оба
набора файлов.

## Быстрый старт

```bash
# Поднять инфраструктуру
docker compose up -d

# Бэкенд
cd backend
./mvnw spring-boot:run

# Фронтенд (позже)
cd frontend
npm install && npm run dev
```
