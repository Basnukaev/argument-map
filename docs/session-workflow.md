# Чек-лист сессии Claude Code

Компактная шпаргалка. Полные правила — в `backend/CLAUDE.md`
(или `frontend/CLAUDE.md` когда появится).

## Перед началом работы
- [ ] Прочитать последнюю запись в `progress.md`
- [ ] Проверить текущий этап в `roadmap.md`
- [ ] Прочитать `decisions.md` — не нарушать принятые решения
- [ ] Прочитать `gotchas.md` — не наступить на грабли
- [ ] Озвучить пользователю: "Последний раз делали X, сейчас задача Y"

## По ходу работы
- [ ] Коммиты с Conventional Commits и scope (`backend`/`frontend`)
- [ ] Новое архитектурное решение → ADR в `decisions.md`
- [ ] Новая ловушка → `gotchas.md`
- [ ] Выполненный пункт → `[x]` в `roadmap.md`
- [ ] Новый термин → `glossary.md`
- [ ] Новая подзадача → дописать в текущий этап `roadmap.md`

## Перед завершением сессии
- [ ] Запись "Сессия N (backend/frontend)" в `progress.md`
- [ ] Раздел "Следующий шаг" написан так, что новая сессия поймёт
      без дополнительных вопросов
- [ ] Все незакоммиченные изменения закоммичены
- [ ] `./mvnw test` проходит (если были изменения кода)
- [ ] `roadmap.md` — все выполненные пункты отмечены `[x]`

## При приближении к лимиту контекста
- [ ] Предупредить пользователя
- [ ] Максимально подробно записать текущее состояние в `progress.md`
- [ ] Включить все незавершённые мысли и конкретный следующий шаг
