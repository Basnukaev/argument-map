## FB-1 🔵 Student AI-форматирование текста + загрузка/экспорт DOCX/PDF
**Концерн (Image #1):** Tiptap крутой. Нужна ОТДЕЛЬНАЯ фича для студентов: AI-форматирование
ИХ текста + скачать DOCX/PDF для печати. Визуальные огрехи AI-edit есть, но потенциал есть.
Ручную загрузку книг никто делать не будет, но возможность оставить. Нужно: **(1) название
вкладки** «улучшение текста через ИИ»; **(2)** загрузка docx/pdf/подобное → отдать ТОТ ЖЕ
файл отформатированным; **(3) КРИТИЧНО: не менять ни одной буквы текста, только форматирование.**
**Триаж:** крупная новая фича, **ADR + спека.** Под-части: (a) student-facing flow (отдельно
от admin lib-pages editor); (b) docx/pdf import → извлечь текст → AI разметка структуры →
Tiptap → экспорт docx/pdf; (c) «ни одной буквы» — гарантия (AI только размечает структуру/
боксы, НЕ переписывает текст — как ADR-042 lib-pages, плюс diff-верификация текста до/после);
(d) tab name 🟡. Зависит от Tiptap (ADR-039) + AI-edit (ADR-042/058). Библиотеки: docx-парс/
экспорт (mammoth/docx), pdf-парс (pdf.js — уже есть react-pdf).

## FB-2 🟢 Скрыть admin/write-UI от гостя (фронт-гейтинг) — недоделка guest-view
**Концерн (Image #3):** гость видит «Админ» в нав-баре, контекстное меню «Редактировать» в
графе и сайд-панели, голосовалку и подобное. Backend guest-view (ADR-064) закрыл API, но
ФРОНТ всё ещё рендерит admin/write-действия анониму.
**Триаж:** фронт-гейтинг, **важно** (недоделка только что зашипленного guest-view). Approach:
нав-пункт «Админ» → только role≥ADMIN; графовые edit-context-menu + side-panel edit-кнопки →
только при canWrite/auth; голосовалка анониму — disabled/hidden (или toast как сейчас).
Аудит реестра write-CTA по анониму. **Quick win (этот спринт).**

## FB-3 🔵 Связать QA и Графы (убрать дублирование, разные визуализации одних данных)
**Концерн:** не должно быть дублирования между вопрос/ответ и графом. Возможность иметь
ТОЛЬКО граф ИЛИ только qa. Связать qa и граф. Пример: вопрос о дозволенности мавлида как QA
и как граф = по сути одно и то же (данные одни, визуализация разная).
**Триаж:** архитектурное, **ADR + спека.** Подумать модель: topic (граф) и question (qa) как
два VIEW одной сущности-дискуссии? Link-таблица topic↔question? Единый источник, 2 рендера?
Влияет на схему БД (topics/questions) + навигацию + права. Решение между альтернативами → ADR.

## FB-4a 🟢 AR-клавиатура — стандартная раскладка (не алфавитная)
**Концерн (Image #4,#5):** клавиатура работает, но порядок алфавитный — заменить на
СТАНДАРТНУЮ физическую арабскую раскладку (Arabic 101). Стандарт (3 ряда):
`ض ص ث ق ف غ ع ه خ ح ج د` / `ش س ي ب ل ا ت ن م ك ط` / `ئ ء ؤ ر لا ى ة و ز ظ` (+ ذ).
**Триаж:** тривиальный swap массива в ArabicKeyboard. **Quick win.**

## FB-4b 🔵 Подсветка участка совпадения при поиске хадисов
**Концерн (Image #4):** при поиске хадиса подсвечивать участок текста, по которому он найден.
Если найден НЕ по иснад-тексту, а по другим критериям — подсветить ГДЕ совпало + пометить в UI.
**Триаж:** backend search должен вернуть matched-field + offsets/snippet; фронт подсвечивает
фрагмент + бейдж «найдено в: матн/иснад/рулинг/…». **Спека (search-relevance).** Средне.

## FB-5 🔵🔵 Редактирование ЛЮБЫХ данных любой сущности (фикс импорта + hide/show)
**Концерн (Image #6):** не только перевод — править ЛЮБЫЕ данные любой сущности (иснады,
передатчики и т.п.) для фикса ошибок импорта/неточностей. **Нельзя менять искомый первоисточник**
(текст хадиса/аята/источника/цитаты). МОЖНО: скрыть/показать участки данных, скрыть
экстремистские данные или имена/мнения заблудших учёных. **«Фундаментальная нетривиальная
фича — проработать ОЧЕНЬ подробно с учётом всех наших особенностей».**
**Триаж:** фундаментальное, **большой ADR + детальная спека.** = P1-1 аудита (manual-edit
эндпоинты) + НО с тремя осями: (a) **защита от реимпорта** (P0-1 — иначе правки затрутся);
(b) **hide/show** флаги на уровне поля/записи (модерация — скрыть имя/мнение/экстремизм без
удаления); (c) **гарантия неизменности первоисточника** (whitelist редактируемых полей —
матн/аят/цитата НЕ в нём). Естественная синергия с overlay-таблицей P0-1 (вариант A): та же
таблица несёт override-значение + hidden-флаг + edited_by/at. Аудит-лог обязателен (кто что
скрыл/исправил). Зависит от P0-1.

## FB-7 🟢🔵 PNG-артефакты + «Все пути» запутанный граф
**Концерн (Image #7,#8,#9):**

- (b) **«Все пути (N)» граф СТРОИТСЯ запутанно** (Image #9 — широкое дерево с пересечениями).

**Триаж:** (a) html-to-image не захватывает текст edge-label (foreignObject/шрифт) → остаётся
тёмный labelBg. Fix: `fontEmbedCSS` в toPng ИЛИ рендерить формулу не через RF-edge-label.
**Quick-medium.** (b) dagre на широком мульти-дереве — анти-overlap/spacing тюнинг
(nodesep/ranksep/ranker/edge-routing для turuq). **Medium.**
